## 📖 About

Auto Reconnect automatically rejoins the last server after a kick or disconnect, with configurable delay, retry limit, and optional notification sound.

---

## ✨ Features
<a name="features"></a>

- **Auto Rejoin** — reconnects to the last server after disconnect.
- **Configurable Delay** — set wait time before reconnect attempt.
- **Retry Limit** — stops after N failed attempts.
- **Notification Sound** — plays when reconnected successfully.
- **Cancel Button** — stop reconnect attempt at any time.
- **Reason Display** — shows disconnect reason on screen.

> 🔑 **100% free** — no key system, no linkvertise, no ads.
